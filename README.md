# Healthy Future

Веб-платформа для удалённого мониторинга здоровья и онлайн-консультаций с врачами.

## О проекте

Дипломный проект. Платформа объединяет телемедицину, ИИ-консультанта и инструменты психоэмоциональной поддержки.

**Чем отличается от аналогов:**
- ИИ-консультант 24/7 для первичной помощи
- Верификация врачей через админ-панель
- Медитации, челленджи, система баллов
- Двухуровневая подписка с куратором

## Технологии

Next.js 16 • TypeScript • Prisma 5 • SQLite • Tailwind CSS • OpenRouter API

## Возможности

**Пациент:** каталог врачей, запись на консультацию, чат с врачом, ИИ-консультант, медитации и челленджи

**Врач:** профиль со специализацией, управление расписанием, доступ к медкарте пациента в чате

**Администратор:** верификация лицензий врачей, управление статусами аккаунтов
